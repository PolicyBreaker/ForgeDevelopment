SETUP GUIDE

🔗 Link Discord account

Real sign-in requires your Discord OAuth application and a secure backend for the redirect and tokens.

This demo is not connected. Never paste your password or account token here.

🖥️ Enable Rich Presence

Custom RPC generally requires Discord Desktop and a local companion that communicates with it.

Hosting the website 24/7 does not keep desktop RPC active.

What can appear in Discord?

✓ Custom Rich Presence: possible with a compatible desktop companion and Discord Desktop running.

✓ Custom status: set manually in Discord; automated changes depend on supported, authorized features.

! Profile bio: this website cannot change it; edit it in Discord itself.

! 24/7 operation: requires an always-on compatible desktop or supported service. GitHub Pages cannot run a desktop process.

Important: OAuth login alone does not enable Rich Presence. Do not share your Discord password or token with third-party websites. This build does not fake a connection or make unsupported API calls.
